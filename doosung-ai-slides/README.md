# 두성종이 AI 업무활용 심화교육(2차) — 강의 슬라이드

데이터로 판단하고, 다시 쓸 수 있는 업무도구를 완성하는 1일 8시간 과정의 발표용 슬라이드입니다.
**HTML 파일 하나**로 되어 있어 더블클릭하면 브라우저에서 바로 열립니다. 설치도, 인터넷 연결도 필요 없습니다.

- 전체 **71장** · 16:9 발표용 · A4 가로 인쇄 대응
- 개정 기준일: **2026-09-15**
- 제작: **Data Thinking Lab** · 이승묵 Ph.D

## 바로 보기

GitHub Pages 주소로 열면 설치 없이 바로 발표할 수 있습니다.
저장소를 내려받았다면 `index.html`(또는 `두성종이_AI심화교육_강의슬라이드.html`)을 더블클릭하세요.

## 조작 방법

| 동작 | 방법 |
|---|---|
| 다음 / 이전 | `→` `←` · 스페이스바 · 화면 좌우 클릭 · 좌측 하단 `‹` `›` |
| 목차 | `O` — 제목 검색 가능, 항목을 누르면 이동 |
| 전체화면 | `F` |
| 화면 끄기(토론용) | `B` — 아무 키나 누르면 복귀 |
| 세션 타이머 | `T` 또는 우측 상단 **시작 / 리셋** |
| 체크 항목 | 항목을 클릭하면 ☐ → ☑ (브라우저에 임시 저장) |
| 체크 초기화 | `C` |
| 인쇄 · PDF | `P` 또는 우측 하단 버튼 — A4 가로 71페이지, 한 장에 한 슬라이드 |

프롬프트 블록 오른쪽 위 **복사** 버튼을 누르면 그대로 AI 창에 붙여넣을 수 있습니다.
브라우저가 클립보드를 막는 경우 자동으로 프롬프트를 선택해 주므로 `Ctrl+C`(Mac은 `⌘+C`)를 누르면 됩니다.

## 다시 만들기

슬라이드 본문은 `src/` 안에 조각으로 나뉘어 있고, 로고는 base64로 내장됩니다.

```bash
python3 build.py
```

`index.html` 과 `두성종이_AI심화교육_강의슬라이드.html` 이 새로 만들어집니다.

| 파일 | 내용 |
|---|---|
| `src/head.html` | 스타일과 화면 뼈대 |
| `src/prelude.js.tpl` | 로고·저작권 표기와 공통 헬퍼 (빌드 시 로고 주입) |
| `src/c1_open_00.js` | 오프닝 · 00 실습 준비 |
| `src/c2_m1.js` | M1-1 ~ M1-4 |
| `src/c3_m2_m3.js` | M2-1 · M2-2 · M3 |
| `src/c4_m4_end.js` | M4 · Work·Skill · 마무리 · 부록 · 클로징 |
| `src/tail.html` | 렌더러와 조작 기능 |
